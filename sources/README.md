# sources/manifest.json

Generated by `scripts/discover.py` from the Judicial Branch's local-rules index,
which is authoritative for each county's name and current effective date.

**Hand edits survive re-discovery.** `discover.py` only overwrites the county
name and effective date; anything else you set is preserved. Two fields exist
for manual correction:

- `documents` — an explicit list of rule documents, which bypasses link
  discovery entirely. Needed when a court serves its rules from a JavaScript
  app (Los Angeles) or behind a portal, so there are no links in the HTML.
- `discovery_note` — why the override exists, for whoever reads this next.

```json
{
  "id": "los-angeles",
  "documents": [
    {
      "url": "https://www.lacourt.ca.gov/courtrules/CurrentCourtRulesPDF/Chap5.pdf",
      "title": "Chapter 5 — Family Division Rules",
      "kind": "local_rules",
      "family_specific": true
    }
  ],
  "discovery_note": "SPA portal; documents set by hand"
}
```

`kind` is one of `local_rules`, `local_forms`, `standing_order`, `fcs`,
`court_guidance`.
